Project Methodology & Development

An architectural breakdown of how this web portal was researched, planned, engineered, and deployed for the Class 9 Information Technology assignment.

Phase 1: Project Scope & Architecture

While the standard assignment submission format suggested a Word document or presentation, building a responsive multi-page web application was chosen to better demonstrate practical digital skills covered under CBSE Subject Code 402.

Core Technical Objectives:

  • Multi-Page Modular Structure: Organizing content across dedicated pages rather than a single long document to keep code clean and maintainable.
  • Responsive Light Theme: Designing a minimal, high-readability user interface using custom CSS without heavy third-party CSS frameworks.
  • Data Visualization: Integrating client-side interactive line charts to illustrate FY 2025–26 revenue trajectories across all four financial quarters.

Phase 2: Research & Data Synthesis

Collecting verified metrics for India's top five IT firms required aggregating information across several corporate and statutory records:

Research Workflow:

  1. Financial Audits: Pulled full-year revenue totals directly from TCS, Infosys, HCLTech, Wipro, and Tech Mahindra investor filings, converting global USD figures to Indian Crores (INR) for fair comparison.
  2. Geographic Mapping: Cataloged international office directories, grouping every operating country into regional tiers (Americas, Europe/UK, and APAC/MEA) by revenue weight.
  3. Analytical Assistance: Utilized AI search and analysis tools as research partners to synthesize large quarterly tables, cross-check total employee numbers, and verify software platforms.

Phase 3: Front-End Development & Engineering

The entire project was developed locally using Visual Studio Code, structuring the application into clear logical directories:

Directory / Component Role in Application
/ (Root) Contains core entry pages: cover portal (index.html), main company directory (companies.html), government links (government-portals.html), documentation, and sources.
/companies/ Dedicated HTML templates for each IT conglomerate detailing financial stats, Chart.js trend curves, software lists, and complete country directories.
/css/style.css A single, shared stylesheet utilizing CSS Flexbox, Grid, custom stat cards, and clean typography to ensure visual consistency across all pages.
/assets/ Houses all local corporate logos, school crests, and site favicon files.

Key Interactive Features Added:

  • Client-Side Search: A real-time JavaScript filter on companies.html allowing instant searching by company name, software, or headquarters city without page reloads.
  • Cross-Platform Flag Delivery: Integrated FlagCDN image embeds so national flags render consistently across all operating systems and browsers.
  • Dynamic Line Charts: Implemented Chart.js line graphs with custom styling to plot financial trends clearly.

Phase 4: Testing, Version Control & Hosting

Before deployment, all links, image paths, and scripts were tested locally using a local development server in VS Code to ensure zero 404 errors or broken relative paths.

Finally, the project was committed to a public GitHub repository and deployed to the web via GitHub Pages, providing an accessible, live HTTPS link for school submission.
